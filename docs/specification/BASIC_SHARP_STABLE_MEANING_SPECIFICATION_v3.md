# BASIC# stable meaning specification v3

Meaning Profile 3 extends Profiles 1 and 2 with game-system declarations. `PLAYER` resolves to the built-in player object; `#name` resolves a Kind; `@name` resolves one defined object; and `it` is legal only where one scene object is established. Comments have no meaning. Declaration and menu order is source order. The nine conformance cases are authoritative.
