# BSharp ASK Compound IF Contract v0.0.38

BSharp ASK remains read-only. For a compound rule it reports one canonical condition string joined by the resolved `and` or `or`, plus the complete `true` and `active` values. Clause details are not separate reactive rules.

`what IF rules are true`, `what IF rules are false`, and world summaries must agree across source, saved BSIR, validated BSBC, BSharp VM, reference runtime, Save restore, and shadow-parity mode. Asking never wakes, rearms, reorders, or mutates a rule.
