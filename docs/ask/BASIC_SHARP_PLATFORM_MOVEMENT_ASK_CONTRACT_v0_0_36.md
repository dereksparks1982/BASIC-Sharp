# BSharp ASK Platform Movement Contract v0.0.36

`ASK "what game systems are declared"` returns Profile 4 platform control declarations exactly as resolved, including key, direction, and whole-number speed. It remains read-only and does not press keys, advance frames, apply gravity, move PLAYER, or alter the world.

Source, saved BSIR, and validated BSBC must return identical declaration answers from the reference runtime and BSharp VM.
