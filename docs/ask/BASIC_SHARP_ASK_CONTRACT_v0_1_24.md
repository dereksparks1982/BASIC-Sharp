# BASIC# ASK Contract v0.1.24

BSharp ASK remains `bsharp.ask.json`, format version 1, with a maximum of 256 questions per command.

v0.1.24 performs no ASK schema or question-language expansion.

ASK remains read-only. Event inspection uses accepted matching rules without executing actions. Human list bounds remain 50 entries while JSON remains complete.

Profile 1 stabilizes answer data for existing supported questions across source, saved BSIR, and restored BSharp Save worlds. Human wording may improve unless an exact message has been explicitly locked.
