# BASIC# Patch Notes v0.1.20

BASIC# now owns the name of its internal representation: **BSharp Intermediate Representation**, normally **BSharp IR** or **BSIR**.

New saved debug files use `.bsir.json` and `bsir.debug.json`. Retired DKIR files do not run. Recompile their original `.bsharp` source.

This build changes identity, filenames, format markers, diagnostics, package metadata, and documentation. It does not change language meaning or runtime world behavior.
