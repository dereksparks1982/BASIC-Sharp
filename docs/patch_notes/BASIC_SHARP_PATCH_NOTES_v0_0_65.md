# BASIC# Patch Notes v0.0.65

v0.0.65 expands the self-hosting execution proof from a smaller BSBC execution parity set into a broader sealed corpus.

The build adds new coverage for repeated events, text mutation, state toggles, follow-up event chains, inventory/carry actions, compound conditions, kind-family matching, and save/restore-sensitive sequences.

This is still not full self-hosting. Ruby remains the bootstrap compiler and referee. The DKLab compatibility bridge remains protected while Elderedd stays the canonical path direction.
