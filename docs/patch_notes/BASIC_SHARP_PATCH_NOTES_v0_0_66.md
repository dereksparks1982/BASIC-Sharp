# BASIC# Patch Notes v0.0.66

v0.0.66 expands the self-hosting execution proof from a smaller BSBC execution parity set into a broader sealed corpus with stronger runtime behaviour coverage.

The build adds new coverage for repeated events, text mutation, state toggles, follow-up event chains, inventory/carry actions, compound conditions, kind-family matching, save/restore-sensitive sequences, event-result parity, final snapshots, and BSharp Save documents.

This is still not full self-hosting. Ruby remains the bootstrap compiler and referee. The DKLab compatibility bridge remains protected while Elderedd stays the canonical path direction.
