# BASIC# Patch Notes v0.1.47

v0.1.47 is a contract and documentation build for the self-hosting runway.

It defines how BASIC# source text is read into deterministic reader records before any future BASIC# tokenizer implementation is allowed to replace or shadow the Ruby bootstrap reader.

The build also records the BASIC# / BSharp universal-standard doctrine: compatibility before replacement, validation before claims, performance as a first-class target, and creator-readable source as the shared language between humans, AI, and compilers.

No game, runtime, web, browser, bytecode, Save, ASK, engine, licensing, sponsorship, or Ruby-replacement behavior changes are included.
