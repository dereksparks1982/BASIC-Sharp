# BASIC# Patch Notes v0.0.23

BASIC# can now answer focused questions about a program and its current world.

Use `--ask` for readable answers and `--ask-json` for complete deterministic tool output. ASK can describe Things and Kinds, list inherited Kind members, inspect values and relationships, show true IF rules, explain world/save status, and reveal which WHEN rule would match an event without running it.

ASK is deliberately narrow and honest. It does not mutate the world, simulate outcomes, silently repair spelling, or claim to understand arbitrary English.
