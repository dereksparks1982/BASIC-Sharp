# BASIC# Patch Notes v0.0.46

v0.0.46 adds the input meaning layer BASIC# needs before plain-English movement can grow into real games.

Creators still write one `CONTROLS for PLAYER` declaration. The runtime can now accept keyboard arrows, mouse/keyboard events, PS5 buttons/sticks, Xbox buttons/sticks, and generic gamepad buttons/sticks, then map them into the same existing engine-neutral movement commands.

This build does not add new source syntax, controller remapping screens, game-engine driver code, haptics, camera control, Profile 8, graphics, or Ruby replacement.
