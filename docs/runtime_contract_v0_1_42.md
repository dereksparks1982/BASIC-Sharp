# BASIC# Runtime Contract v0.1.42

v0.1.42 changes no runtime meaning. `BasicSharp::Runtime` remains the protected reference execution path and `BasicSharp::BytecodeVirtualMachine` remains preferred. Both must implement Stable Meaning Profiles 1–7 exactly.

Trial by Fire adds independent expected traces, repeated deterministic hashes, simultaneous-world isolation, boundary follow-up chains, Save/restore campaigns, read-only ASK campaigns, and whole-language parity. These are validation obligations, not creator-facing features.

Every generated runtime fixture whose bytes contain or depend on `BasicSharp::VERSION` must be regenerated as part of one complete version-bearing inventory. A stale fixture is a candidate failure, not permission to weaken validation.

The future BASIC# Semantic Oracle is not implemented here. When separately approved, it must obey Derek-approved semantics, report uncertainty honestly, and remain independent of the production compiler and VM.
