# DK Godot v0.2.88 Versioned Deliverable Archive Name Addendum

Every user-facing DK archive must carry a numeric version in its filename.

This applies to:

- changed-files builds and patches;
- hotfixes;
- handshakes and transfer bundles;
- external Main backups;
- development utilities released as part of the DK tool suite.

Date-only or descriptive-only names are not acceptable for current deliverables. A stale transfer package must never be presented in place of the current installable build.

Before delivery, verify that the package filename, `project.godot`, runtime build string, active scene version labels, build documentation, and backup name all agree.
