# DK Godot v0.3.69 Company Bible Addendum: MIT Integration and Visible UI Rule

**Date:** 2026-07-11  
**Status:** Mandatory  
**Scope:** Demon Killer / Elderred Interactive production workflow

## MIT integration doctrine

Do not reinvent the wheel when a useful MIT-licensed system already solves a problem and fits Demon Killer. After licence review and technical fit checks, prefer integration plus DK-native refinement over rebuilding every foundation from scratch.

This does not permit blind imports. Check bundled assets, fonts, dependencies, compatibility, and architecture impact first. If it works and fits, add it, document it, test it, then improve it over time until it belongs to DK.

## Visible UI rule

UI fixes must be judged against owner-visible screenshots and play conditions, not only internal logical dimensions. For text panels, window size and font size must be tuned together.
