# DK Godot v0.2.97 DK Live Builder Exact Menu Name Addendum

**Date:** 2026-07-07  
**Status:** Mandatory  
**Scope:** DK Live Builder editor-menu wording and instructions

## Rule

The exact tool name is:

```text
DK Live Builder
```

The exact Godot editor path is:

```text
Project > Tools > DK Live Builder
```

Do not call the menu item `DK: Open Live Builder`, and do not direct the owner only to a vague bottom-panel location.

The bottom-panel item may be mentioned after the exact menu path has been given, because opening the tool makes its **DK Live Builder** panel visible.

All future code, controls records, patch notes, system documentation, handoffs, and user instructions must use the exact name unless the owner explicitly renames the tool again.
