# Company Bible Addendum - No Image Generation Unless Explicitly Ordered

## Version

DK Godot v0.1.18

## Mandatory Rule

Do not generate images for DK unless Derek explicitly and unmistakably asks for an image, picture, drawing, visual, or says wording such as “make a picture of.”

Design talk is not image permission. Mentions of a cursor, ghost-ball, Navi-like helper, visual direction, art style, or game object should be treated as text, code, and design work only unless Derek clearly asks for generated artwork.

## Reason

The DK workflow depends on fast text/code iteration. Unrequested image generation causes lag, disrupts the thread, and violates Derek's stated project preference.
