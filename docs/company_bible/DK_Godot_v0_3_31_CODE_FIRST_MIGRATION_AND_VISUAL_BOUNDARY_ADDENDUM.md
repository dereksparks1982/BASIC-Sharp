# DK Company Bible Addendum v0.3.31
## Code-first migration and visual boundary

This addendum records an owner-directed working boundary.

1. Dick retains control of final visual assembly, UI appearance, sprite placement, and animation appearance.
2. ChatGPT should concentrate on code, system migration, integration, debugging, documentation, validation, and packaging.
3. Do not generate images unless Dick explicitly requests image generation.
4. Planning, discussion, and design agreement are not permission to edit or package. Begin a build only after explicit build, patch, or hotfix authorisation.
5. The legacy Zelda-style `scenes/Main.tscn` is a protected donor vault. Read and salvage from it, but do not edit it without the Main-specific explanation and approval required by the Company Bible.
6. Migrate gameplay systems into the seamless-region architecture. Do not replace the seamless streamer with the obsolete edge-transition cell manager.
7. Rejected visual builds remain historical records and are not approved visual baselines.
