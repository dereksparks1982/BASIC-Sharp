# DK Godot v0.3.57 Build the Game We Want Addendum

**Date:** 2026-07-11  
**Status:** Mandatory direction

Demon Killer is built first as the game Derek and the team genuinely want to play. Do not flatten its identity, difficulty, old-school depth, spiritual atmosphere, practical systems, or unusual decisions merely to court the broadest possible audience.

Other players are welcome to love it, but mass appeal is not the design authority. Do not use focus-group fashion, market-chasing, or design-by-committee as grounds to erase a deliberate Demon Killer choice. Accessibility may remove needless barriers, but it must not hollow out the game or ridicule the player.

The governing order is:

1. Build the game we believe in.
2. Make its systems work and remain repairable.
3. Explain its rules honestly.
4. Welcome the audience that connects with it.
5. Never trade its spine for hypothetical universal approval.
