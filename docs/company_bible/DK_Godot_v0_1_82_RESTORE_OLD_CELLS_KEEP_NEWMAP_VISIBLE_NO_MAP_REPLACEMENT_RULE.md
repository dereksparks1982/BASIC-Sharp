# Company Bible Addendum - No Map Replacement / No Cell Deletion

Version: v0.1.82

Rule reinforcement:
- Adding a new map preview must not replace, delete, hide, or overwrite existing map cells, door-room cells, doors, protected objects, or user-made cells.
- New saved preview cells must be added alongside existing work unless Derek explicitly orders a destructive replacement.
- Editor preview changes must open the correct scene without making existing saved cells disappear from that scene.
- Every correction is logged, even when the change is small.
