# Company Bible Addendum - Immediate Patch Inclusion Rule

## Version

DK Godot v0.1.16

## Mandatory Rule

When Derek explicitly asks for a patch, build, feature, fix, or edit, the requested work must be included in the next available patch/build.

Do not defer it to a later build unless Derek explicitly says to wait, hold, or leave it for later.

## Documentation Requirement

Every patch/build must include the appropriate record trail:

- patch notes
- changelog
- session/development log
- CODEX/design note when gameplay, lore, control, world, or system rules change
- Company Bible update when workflow/company law changes

## Enforcement Note

Partial packs that skip known requested items are not acceptable unless the limitation is clearly stated before delivery.
