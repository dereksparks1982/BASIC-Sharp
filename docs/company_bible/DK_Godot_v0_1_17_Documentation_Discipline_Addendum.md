# Company Bible Addendum - Documentation Discipline Reaffirmed

## Rule
DK builds and patches must keep thorough records. Patch notes, changelogs, session logs, and CODEX/design notes are part of the work.

## Context
Derek emphasized that DK is documented so thoroughly that other AI tools have commented on it. That standard must be preserved.

## Practical Requirement
When a feature changes gameplay, controls, systems, lore, workflow, or build process, it must be recorded in the appropriate documentation path in the same patch/build.

## Current Application
v0.1.17 records movement-weight changes, enemy movement tuning, and the next planned drag/drop cell snapping target.
