# Company Bible Addendum - v0.2.98 Approved Main Menu Art Lock

Date: 2026-07-07
Status: Mandatory

## Approved art

The v0.2.98 paper-doll-style altar menu image and its companion Demon Killer font specimen are approved project art.

The active menu image must not be regenerated, reinterpreted, replaced, recolored, cropped, stretched, or redesigned unless Derek explicitly orders a later revision. When Derek asks to build from approved art, do not trigger image generation again.

## Menu presentation

The approved menu's wording and composition are the visual source of truth. Use transparent interaction layers over the artwork rather than approximating its buttons, frames, lettering, plants, altar, corpse staging, or panels with generic controls.

The only standing exception is live build-version hygiene: concept-art version text must be covered by the actual current DK version rather than allowing a false or stale version to remain active.

## Music lock for this menu

The Ashbringer title theme currently in the project is approved for this menu. Do not replace, retune, or remove it without Derek's instruction.

## Font honesty

A font specimen image is not a finished font file. It may guide future font production, but no build may claim that a complete custom font exists until actual glyph assets, metrics, spacing, punctuation, import settings, and tests have been produced and documented.
