# DK Godot v0.3.02 Faith, Map, and Building Layering Addendum

## Faith Is Separate

Faith is a separate progression resource from individual skill experience. Future implementation must not collapse Faith into generic XP or award it without an approved spiritual, moral, religious, or world-system rule.

## Region Map Control

`Ctrl+M` is the reserved control for opening and closing the regional map. Active-control documentation must preserve this binding unless Derek explicitly changes it.

## Mouse-Wheel Zoom

Mouse-wheel zoom is an approved primary convenience control alongside Up/Down Arrow zoom. Future map or UI work must not remove it casually.

## Building Layering

Regional outdoor terrain must remain separate from building interiors. Grass, mud, water, snow, or other regional textures must never bleed through opaque indoor floors or walls. Buildings that reveal interiors should use a deliberate roof visibility layer rather than flattening roof, walls, interior, and terrain into one contaminated image.

## Approved Sanctuary Source

The complete approved top-down Sacrifice Sanctuary artwork is the source of truth for the B2 building. Technical derivatives must preserve the complete upper wall and may not crop away approved architecture.
