# BASIC# Runtime Contract v0.1.58

v0.1.58 does not change runtime behavior.

The build adds a self-hosting bridge parity harness for validating BSBC bytes emitted from approved small compiler subset fixtures under Ruby referee control. Profiles 1 through 7, BSharp bytecode, the bytecode VM, runtime transition, save/restore, ASK, input, movement, and Trial by Fire behavior remain under existing validation gates.
