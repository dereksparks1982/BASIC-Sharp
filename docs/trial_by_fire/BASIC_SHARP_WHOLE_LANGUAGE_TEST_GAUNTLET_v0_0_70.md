# BASIC# Whole-Language Test Gauntlet v0.0.70

v0.0.70 turns the gauntlet into a stronger milestone gate.

## Expanded defaults

- Event execution paths: 128,000 per path.
- Platform movement frames: 128,000.
- Combined movement plus input-action frames: 64,000.
- ASK questions: 32,000.
- Save checkpoints: 1,250.
- Simultaneous isolated worlds: 320.
- Generated programs: 384.
- Hostile mutations per boundary: 3,072.

## Added phase

The combined movement plus input-action phase runs keyboard, mouse, PS5, Xbox, generic gamepad, and frame events through source and BSBC-loaded models. The command streams must stay identical.

## Purpose

This build is the anvil before object interaction. It proves movement and input can survive a larger cross-profile runtime storm before more game-world behavior is added.
