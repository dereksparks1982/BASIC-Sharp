# BASIC# Runtime Contract v0.1.39

The BSharp VM remains the preferred runtime; `BasicSharp::Runtime` remains the protected reference oracle. Profile 7 adds two-sided IF settlement using IF / OTHERWISE and no ELSE alias.

Both runtimes must agree on startup branch, every truth transition, quiet unchanged state, final world, log, ASK result, saved branch, restore behavior, ordering, and loop failure. Older meanings keep their accepted behavior.
