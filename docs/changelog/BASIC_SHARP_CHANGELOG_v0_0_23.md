# BASIC# Changelog v0.0.23

## Added

- `--ask` repeated read-only inspection questions.
- `--ask-json` deterministic machine-readable answers.
- Thing, Kind, inherited membership, state, value, relationship, event-match, IF, world, and save questions.
- Ambiguous-name and unsupported-question explanations.
- 256-question boundary and bounded human lists.
- ASK sample source, BSIR, save, tests, stress lane, and contracts.

## Preserved

All accepted BSharp IR, runtime, Kind, IF, selection, value, event, and save behavior remains intact.

## Excluded

No new source syntax, ASK Head, official word, unrestricted English, spell correction, event simulation, mutation, arithmetic, bytecode, VM, GUI, engine integration, self-hosting, or new DK-prefixed name.
