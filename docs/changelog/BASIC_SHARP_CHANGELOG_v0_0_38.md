# BASIC# Changelog v0.0.38

## Added

- Plain-English `and` and `or` compound IF conditions.
- Stable Meaning Profile 6 and BSharp Bytecode Profile 6.
- `ALL_CONDITIONS` and `ANY_CONDITIONS` bytecode records.
- Save format 6, compound ASK reporting, runtime-transition parity, deterministic fixtures, sample, tests, and a 20,000-event-per-runtime stress lane.

## Preserved

- All accepted Profile 1–5 meanings and runtime behavior.
- Every committed Profile 1–5 BSBC and diagnostic disassembly artifact byte-for-byte.
- Accepted IF source ordering, false-to-true semantics, rearming, and loop protection.

## Excluded

Mixed connectors, precedence, parentheses, nested groups, general `not`, `OTHERWISE`, collection conditions, engine work, editor work, and self-hosting.
