# BASIC# Changelog v0.0.28

## Added

- Complete arbitrary `.bsbc` loader and structural validator.
- Trusted deeply frozen bytecode program model.
- Binary-derived deterministic disassembly.
- CLI bytecode summary, `--disassemble-bytecode`, and `--against` meaning comparison.
- Forty-one deterministic malformed-bytecode fixtures and full truncation sweep.

## Changed

- Active version surfaces advanced to v0.0.28.
- Bytecode Profile 1 now records the implemented loader boundary.
- Generated BSIR and BSharp Save samples advanced to v0.0.28.
- Existing v0.0.27 BSBC sample binaries remain byte-identical.

## Not changed

No BASIC# syntax, meaning, runtime behavior, BSIR schema, Save schema, ASK schema, bytecode layout, VM, or execution behavior changed.
