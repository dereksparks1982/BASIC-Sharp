# BASIC# Changelog v0.1.59

## Added

- Small compiler subset runtime smoke specification, implementation, tests, and validation tool.
- Runtime smoke coverage for selected self-hosting fixture corpus programs.
- Golden digests for smoke event results, final world snapshots, save documents, BSBC binaries, and loader summaries.

## Unchanged

- Ruby remains the bootstrap and referee.
- BASIC# is not claimed self-hosted.
- Bytecode and BSBC names remain stable.
- No production runtime behaviour changes are introduced.
