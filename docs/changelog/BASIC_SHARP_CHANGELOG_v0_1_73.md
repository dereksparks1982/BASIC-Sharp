# BASIC# Changelog v0.1.73

## Plain-English Object Interaction Actions

BASIC# now executes the already-recognized creator words `(open`, `(close`, `(lock`, and `(take` end to end. The resolver lowers these words onto the existing proven `change` and `carry` primitives so BSIR, BSBC, BSharp VM, Ruby referee parity, and CONTEXT interaction remain aligned.

No Profile 8 or bytecode-format change is introduced.
