# BASIC# Runtime Contract v0.1.65

v0.1.65 does not change production runtime behaviour.

The release expands proof around existing behaviour by adding a larger small compiler subset execution corpus. The BSharp VM path must continue to match the Ruby referee runtime for event results, final snapshots, and BSharp Save documents.

No Profile 8 is introduced. Profiles 1 through 7 remain the accepted runtime and bytecode profile surface.
