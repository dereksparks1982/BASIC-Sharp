# BSharp Save Contract v0.1.37

Meaning Profile 5 uses BSharp Save format version 5 and fingerprint algorithm `sha256-bsir-meaning-v5`.

Whole-number values remain typed entries and must remain within 0 through 2,147,483,647. Save files preserve the settled world and active threshold IF state. Restore validates format, fingerprint, Thing order, value names/types/ranges, canonical conditions, and active truth before replacing the current world. Any failure leaves the running world unchanged.
