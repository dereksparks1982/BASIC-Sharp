# BSharp Save Contract v0.0.24

BSharp Save remains `bsharp.save.json`, format version 1, with fingerprint algorithm `sha256-bsir-meaning-v1`.

v0.0.24 performs no save schema migration.

Profile 1 stabilizes settled-world preservation of Thing order, identity, Kind, states, relationships, whole-number values, and IF active state. Loading remains atomic and does not replay START, startup IF rules, or startup follow-up events.

The creator-version label is recordkeeping and is excluded from normalized Profile 1 save meaning. Program fingerprints and world meaning remain deterministic.
